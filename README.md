# AFS

AFS(Aircraft Flight Simulation) 관련 개발 및 시뮬레이션 프로젝트입니다.

## 프로젝트 구성

```text
AFS
├── AI/          # AI 관련 구현
├── AI_HILS/     # HILS 기반 시험 환경
└── JSBSIM/      # JSBSim 기반 비행 시뮬레이션
```

## 주요 내용

* JSBSim 기반 비행 동역학 시뮬레이션
* AI 기반 비행 제어 및 시뮬레이션 기능 구현
* HILS(Hardware-In-the-Loop Simulation) 환경 구성 및 시험
* 비행 시나리오 생성 및 시뮬레이션 수행

## 개발 환경

* C/C++
* JSBSim
* HILS
* Windows

## 참고

본 프로젝트는 비행 시뮬레이션 및 관련 기능 개발을 목적으로 작성되었습니다.
